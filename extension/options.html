Scheduler telemetry settings

Remote collector

Run npm run collector on the receiving machine. It prints the URL and token to paste here.

Live sites

localhost and 127.0.0.1 are always on. Other sites must be enabled one by one (popup → "Enable on this site", or add one here). Reload a tab after enabling it.

Pages are probed for timings only (long frames, slow interactions, load timing), but each event carries the page's origin + path, so with streaming on the collector receives a browsing trail.
